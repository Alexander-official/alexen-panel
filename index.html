What's inside

The additions on top of Marzban.

🛡️

Hysteria2

Native Xray-core Hysteria2 (works on nodes too) with Salamander obfuscation.

📡

Online IPs

See who is connected, on which node and inbound, in real time — and kick a session with one click.

🔢

IP & device limits

Cap simultaneous IPs and devices (HWID) per user; extra ones are blocked until an earlier one drops.

👥

Resellers

Creator, sudo admins and resellers with user/traffic quotas, host groups and per-reseller copy/limit permissions.

🔗

Subscriptions

Custom sub-page templates per user state, placeholders incl. {token}, and custom domain/path.

💾

Backups & updates

Back up, restore and update from the panel — it backs up first and rolls back a failed update.

REST API

Automate everything. Most endpoints take a bearer token.

# 1) get a token
curl -X POST https://YOUR-PANEL/api/admin/token \
     -d 'username=<admin>&password=<password>'
# -> {"access_token": "…", "token_type": "bearer"}

# 2) call the API
curl https://YOUR-PANEL/api/users \
     -H 'Authorization: Bearer <access_token>'

Subscription-message placeholders:

{username}{used}{limit} {remaining}{expiretime}{days} {status}{token}
